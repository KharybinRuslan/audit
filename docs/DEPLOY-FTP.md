# Выгрузка на хостинг (FTP) после сборки

Когда сайт готов к публикации, **сначала соберите статику** на своём компьютере, **затем** заливайте файлы на Бегет по FTP.

В Cursor можно написать ассистенту, например: *«Выполни в корне проекта `npm install` и `npm run build` перед выгрузкой»* — билд сделают здесь, вам останется забрать файлы и залить по FTP.

## Сборка перед выгрузкой

В корне проекта (где лежит `package.json`):

```bash
npm install
npm run build
```

Команда `npm run build` обновляет:

- `vendor/swiper/swiper-lite.min.js` и `vendor/swiper/swiper-lite.min.css`
- `components/stages/stages.min.css`
- `components/site-footer/site-footer.min.css`
- `components/reviews/reviews.min.css`

Без этого на сайте могут быть устаревшие или отсутствующие минифицированные файлы.

**На хостинге Node.js не нужен** — достаточно загрузить уже собранные файлы.

---

## Что заливать по FTP

Заливайте **всю структуру сайта** в корень домена (или в подпапку, если так настроен домен), как у вас локально в OSPanel: `index.php`, `pages/`, `components/`, `css/`, `js/`, `img/`, `font/`, `includes/`, `vendor/`, `.htaccess` и т.д.

---

## Что **не нужно** выгружать на хост

| Путь / маска | Зачем не грузить |
|--------------|------------------|
| **`node_modules/`** | Зависимости только для сборки; на сервере не используются, объём огромный. |
| **`.git/`** | История Git на хосте не нужна (если копируете из репозитория). |
| **`.cursor/`** | Настройки редактора Cursor. |
| **`.vscode/`** | Настройки VS Code. |
| **`*.log`**, **`npm-debug.log*`** | Служебные логи. |
| **`.env`**, **`.env.*`** (если появятся) | Секреты не должны лежать на shared-хостинге в открытом виде без необходимости. |

### Опционально (можно не грузить, сайт работает)

Эти файлы нужны **только для повторной сборки** на вашем ПК. На FTP их можно не выкладывать, чтобы не засорять хост:

| Путь | Примечание |
|------|------------|
| **`tools/`** | Исходники для esbuild (Swiper). |
| **`package.json`** | Скрипты npm. |
| **`package-lock.json`** | Фиксация версий npm. |

Их лучше **хранить в Git** у себя, чтобы потом снова выполнить `npm run build` после правок CSS/Swiper.

---

## После выгрузки

- Проверьте сайт по HTTPS/HTTP домена.
- Если ЧПУ не работает, на Бегете должен быть включён **Apache**, читается **`.htaccess`** (на тарифах с Apache это обычно так).

---

## Краткий чеклист

1. `npm install` → `npm run build`
2. FTP: загрузить проект **без** `node_modules` и **без** пунктов из таблицы выше
3. Открыть сайт в браузере и проверить главную и внутренние страницы
